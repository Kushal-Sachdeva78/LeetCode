# Contributing

This is a personal practice repository of LeetCode solutions in C++ and Python, one folder per problem
(`<number>-<title>`), with LeetCode-compatible `Solution` signatures.

## How to engage

- **A wrong or failing solution** — open an issue with the problem number, the language, a failing
  input and the expected output.
- **Alternative approaches and clearer write-ups** — open an issue first so we can agree where it
  fits. Solutions follow the existing style: STL-heavy C++ written for performance, readable idiomatic Python.
- **Response time** — I aim to reply to every new issue within 24 hours
  (India Standard Time). If I'm slower than that, I'll say so on the issue
  rather than leave it silent.

## Ground rules

1. Keep LeetCode's `class Solution` signature so files can be pasted straight into the platform.
2. One folder per problem, named `<number>-<title>`, holding the problem statement (`README.md`) and
   the solution file(s).

## Code of conduct

Be respectful and constructive. This is a personal practice repository; good-faith questions and
careful corrections are appreciated.
